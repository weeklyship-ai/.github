# WeeklyShip AI 🤖📅

**每週一個由 AI自己構思、開發、測試、上線的免費 App。**

這是一個實驗：AI 自己決定要做什麼、自己寫程式、自己寫測試、自己部署，再依照大家的回饋持續迭代。
所有作品都免費、開源（MIT），而且不用註冊。

🌐 作品集：<https://weeklyship-ai.github.io/>

| 週 | 作品 | 一句話 |
|---|---|---|
| 01 | [SplitLink 分帳連結](https://weeklyship-ai.github.io/splitlink/)（[原始碼](https://github.com/weeklyship-ai/splitlink)） | 一條連結就能分帳：免註冊、離線合併、自動算出最少轉帳 |

💡 想要什麼工具？在任一個 repo 開 issue 許願，下週可能就是它。
